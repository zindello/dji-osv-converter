dji_osv_converter.pipeline

End-to-end dual-fisheye -> levelled equirectangular pipeline.

Everything needed comes out of the OSV file itself:

per-unit lens calibration    -> osv_calibration.read_osv_calibration
per-frame orientation        -> metadata.read_metadata (+ read_highrate)
camera<->IMU mount rotation  -> osv_calibration.read_mount_rotation
fisheye -> equirect maps     -> project.build_map
seam blending                -> stitcher.seam_weights / blend

The handful of values that are NOT in the OSV - DJI's layout conventions and a few defaults - live in constants.py with their provenance.

Levelling modes (Stitcher360.levelling):

plain The constant layout convention K_PLAIN; matches DJI's raw, unlevelled export - the image follows the camera. rocksteady Stabilisation only: counter-rotate toward the Gaussian-smoothed orientation trajectory, so shake is removed while the gross tumble passes through. Measured smoother than DJI's own export (jitter 0.027/0.071 vs 0.046/0.118 deg/frame calm/moving). rocksteady_horizon HorizonLevelling: all three axes locked to a fixed level world view, from the per-frame IMU quaternion. Matches DJI's rocksteady+horizonlevelling and holds yaw tighter (DJI wanders under violent motion). none Identity - the raw rig frame (~90 deg off DJI's layout).

def maps_for( self, frame: int = 0) -> tuple[list[dji_osv_converter.calibration.CameraMap], numpy.ndarray]:

Remap tables + seam weights in the camera-rig frame.

These are orientation-independent and built once: the fisheye->rig projection is fixed by the calibration. Per-frame levelling is applied afterwards as a cheap equirect rotation. frame is accepted for API compatibility but does not affect the maps.

def lsc_gains(self) -> list[numpy.ndarray] | None:

Per-lens devignetting gain maps (equirect), or None if no LSC data.

See lsc_gain_map() for why this is OFF by default.

def bridge(self) -> numpy.ndarray:

Per-file IMU-body -> equirect bridge: C_UP_FORMAT @ mount.

The mount (OSV header 1.3.1, the magnetic-mount skew, ~13 deg on the units seen so far) is PER-UNIT and must come from each file; only the format-level part is a constant. det = -1 (see constants.py).

def rs_tables(self):

Static rolling-shutter tables per lens: (tau, J) at 1/RS_TABLE_DS res.

tau (h, w) is the source SENSOR-ROW fraction in [0, 1] for each output pixel; J (h, w, 2, 3) is the sensor-plane shift (px) per radian of rig-frame rotation about x/y/z, built numerically from three perturbed projection maps. Zero where the lens has no coverage.

def rs_args_for(self, frame: int):

Per-frame rolling-shutter correction: (theta (S,3) f32, t0, scale).

theta[k] is the rig-frame rotation vector (radians) of the camera at sub-frame time k/(S-1) relative to frame start (where the per-frame quaternion and the stabilisation reference live). The GPU evaluates each pixel's sample position as (t0 + scale * tau) * (S-1). Returns None when the high-rate track is missing for this frame.

def levelling_for(self, frame: int) -> numpy.ndarray:

The rig-frame rotation to apply for this frame, per levelling.

See the module docstring for what each mode does and how it was validated against DJI's own exports.

Stitch a pair into the camera-rig frame (no levelling).

def stitch( self, fisheye0: numpy.ndarray, fisheye1: numpy.ndarray, frame: int = 0, flow: bool = False, exposure: bool = False, multiband: bool = True) -> numpy.ndarray:

Stitch one frame pair to a levelled equirectangular panorama (CPU).

Stitches in the rig frame (fixed maps) then rotates the result per the levelling mode. flow=True morphs across the seam to absorb parallax; multiband=True uses Laplacian-pyramid blending; exposure matches the sensors across the seam (OFF by default - the OSV footage arrives exposure-matched by the in-camera ISP).

def seam_agreement( self, fisheye0: numpy.ndarray, fisheye1: numpy.ndarray, frame: int = 0) -> float:

Inter-camera correlation in the overlap; a calibration quality check.

Needs no reference output. 1.0 would be perfect; parallax puts a practical ceiling well below that for close subjects.

def horizon_lock_rotation(raw_f: numpy.ndarray, bridge: numpy.ndarray) -> numpy.ndarray:

Full horizon-levelling rotation for one frame (all three axes locked).

Locks the view to a FIXED world orientation: world-up at the output pole (pitch+roll level) and world-forward as the heading (yaw locked). Both come from the SAME instantaneous IMU quaternion via bridge (the per-file IMU->equirect map C_UP_FORMAT @ mount) - the key to a clean yaw lock: using the smoothed orientation for the heading makes it lag the real content during fast motion and the world swings in azimuth (measured: a 56 deg swing with 6 deg/frame jerks); the consistent instantaneous basis pins every world-fixed point (0 jerk), strictly steadier than DJI.

Returned as the rig->output rotation R: the stitch samples output pixel direction d at R @ d, so world-up as the middle column puts it at the output pole (d = [0,1,0]).

def smoothed_rotation_track(quats: numpy.ndarray, sigma: float = 15.0, order: str = 'wxyz'):

Per-frame IMU rotation matrices and their Gaussian-smoothed trajectory.

Returns (raw (N,3,3), smooth (N,3,3)). Smoothing is a Gaussian-weighted mean of the rotation matrices, re-orthonormalised (SVD) per frame - a matrix low-pass that removes shake while keeping the tumble.

def transfer_gamma(path: str | pathlib.Path) -> float:

Encoding transfer gamma from the video stream's declared color_trc.

def lsc_gain_map( cam_map: dji_osv_converter.calibration.CameraMap, calib: dji_osv_converter.osv_calibration.CameraCalib, gamma: float = 2.2) -> numpy.ndarray | None:

Per-output-pixel devignetting gain for one lens, or None if no LSC data.

Inverts the f-theta radial map to recover the undistorted radius the factory curve (calibration fields 22/23) is authored in, looks up V, and returns (1/V)^(1/gamma) matching cam_map. gamma is the file's encoding transfer (see transfer_gamma()).

NOTE: the OSV fisheyes arrive already devignetted by the in-camera ISP, so applying this on top double-corrects (a visible bright arc at the seam) - it is OFF by default in video.convert() and retained only for footage that is not already ISP-corrected.
