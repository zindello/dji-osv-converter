## CRITICAL DISCOVERY

### OSV File Structure
- **Format**: ISO Media / MP4 (ISO 14496-12:2003)
- **Camera Type**: Osmo 360 (DJI omnidirectional camera)
- **Streams**:
  - 2x HEVC video streams (3840x3840 each) - different lens perspectives
  - 1x Audio stream (WAV, 48kHz stereo)
  - 1x DJMD metadata stream (index 3) - **CRITICAL**
  - 1x DJMD metadata stream (index 4)
  - 2x DBGI streams (indexes 5-6) - debug info?

### Metadata Format
- **Type**: Protocol Buffer (protobuf) - binary serialized format
- **Schema**: `dvtm_oq101.proto` (DJI Video Telemetry Metadata v0.1.0.1)
- **Content**: 
  - Camera calibration data
  - Orientation/gimbal information
  - Lens configuration
  - Frame-by-frame stabilization vectors
  - Stitching parameters for the 360 views
